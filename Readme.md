Autonomous Mentor 

An Agentic AI-based Autonomous Mentor System built using Google Agent Development Kit (ADK). This project acts as a personalized digital mentor that guides users across learning, career growth, habits, wellness, and skill-building through goal-driven, multi-agent collaboration.

🚀 Project Overview

The Autonomous Mentor Agentic AI is designed to simulate a proactive mentor that:

Understands user goals and context

Plans step-by-step guidance autonomously

Uses specialized agents to execute tasks

Tracks progress and adapts recommendations over time

The system follows Agentic AI principles such as autonomy, reasoning, planning, memory, and tool usage.

🧠 Core Features

🎯 Goal-Oriented Mentorship – Breaks long-term goals into achievable tasks

🤖 Multi-Agent Architecture – Specialized agents collaborate to solve problems

📚 Personalized Learning Paths – Adapts content based on user level and progress

🧪 Quiz & Assessment Generation – Auto-generated quizzes after topic completion

📈 Progress Tracking – Maintains user history and growth trajectory

🧘 Wellness & Habit Support – Encourages balance alongside productivity
